# PV-ADR-TASK-1
Pharmacovigilance - ADR Identification and Reporting

# Objective
To understand the basics of adverse drug reactions (ADRs), identify a suspected ADR from a patient case, and learn how to document it using an ADR reporting form.

# Task
A mock patient case was analyzed to identify the suspected drug, adverse reaction, causality, severity, seriousness, dechallenge, and outcome.

# earning Outcomes
- Basic concepts of Pharmacovigilance
- Identification and assessment of ADRs
- Understanding drug toxicities
- Practical use of an ADR reporting form
